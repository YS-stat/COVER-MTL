# COVER-MTL

Code and reproducibility materials for covariate-overlap regularized
multi-task learning (COVER-MTL).

For tasks \(t=1,\ldots,T\), COVER-MTL uses

```text
f_t(x) = g(x) + z(x)^T beta_t,    sum_t beta_t = 0,
```

and integrates task-specific coefficients through second-moment matrices of
the learned shared representation. The implementation optimizes the
covariate-overlap penalty with exact auxiliary consensus variables, avoiding
matrix inversion during neural-network training.

## Installation

Python 3.9 or later is required.

```bash
python -m pip install -e ".[test,plot,real-data]"
pytest
```

CUDA is optional. All experiments accept CPU devices, although the full
simulation and GTEx analyses are substantially faster on GPUs.

## Repository layout

- `src/cover_mtl/`: COVER-MTL, comparison methods, simulation data-generating
  processes, training utilities, launchers, and aggregation tools.
- `tests/`: algebraic, implementation, randomness, and end-to-end checks.
- `experiments/gtex/`: the final donor-disjoint GTEx brain-tissue analysis.
- `paper_results/`: frozen manuscript-facing summaries, tables, figures, and
  the script used to rebuild them.
- `SIMULATION_PROTOCOL.md`: complete settings and commands for the formal
  simulation blocks.
- `VALIDATION.md`: implementation and result-validation checks.

## Simulations

The formal suite covers the two main joint-heterogeneity settings,
homogeneous and single-heterogeneity controls, overlap and posterior-strength
mechanism experiments, sensitivity analyses, increasing numbers of tasks and
covariates, an overlap-gated outlier diagnostic, and fixed-representation
theory verification. Each performance setting uses independent training,
validation, and test data. The primary, control, mechanism, scaling, and
outlier settings use 100 paired repetitions.

For example, the main experiments can be launched with

```bash
python -m cover_mtl.simulations.launchers.primary \
  --output-dir results/main \
  --replicates 100 \
  --scenarios both_overlap_aligned \
  --within-scales 0.20,0.30
```

See [`SIMULATION_PROTOCOL.md`](SIMULATION_PROTOCOL.md) for all commands,
settings, tuning rules, and reported metrics.

## GTEx analysis

The real-data experiment predicts `JAM2` and `SH2D2A` expression across 11
GTEx v8 brain tissues. Splits are donor-disjoint, and preprocessing and model
selection use training and validation donors only. The analysis uses 20
repeated five-fold cross-validation partitions and compares COVER-MTL with
ARMUL, FLARCC, HPS, Pool, STL, and MMoE.

Raw GTEx data are not redistributed. Public source URLs are listed in
[`experiments/gtex/data_manifest.txt`](experiments/gtex/data_manifest.txt).
Download and prepare the data with

```bash
python experiments/gtex/download_data.py
python experiments/gtex/prepare_data.py \
  --raw-dir experiments/gtex/raw \
  --output-dir experiments/gtex/prepared
```

Run and aggregate the analysis with

```bash
python experiments/gtex/launch_repeated_cv.py \
  --data experiments/gtex/prepared/gtex_v8_brain_module137.parquet \
  --output-dir experiments/gtex/results/repeated_cv_v1 \
  --repeats 20 --workers 12 --threads-per-job 2 \
  --devices cuda:0,cuda:1,cuda:2,cuda:3

python experiments/gtex/aggregate_repeated_cv.py \
  --input-dir experiments/gtex/results/repeated_cv_v1 \
  --repeats 20
```

Further details and frozen numerical summaries are provided in
[`experiments/gtex/README.md`](experiments/gtex/README.md).
The machine-readable aggregate files are retained in
`experiments/gtex/frozen_results/`; raw expression and fold-level training
artifacts are not included.

## Manuscript results

The numerical values, LaTeX tables, and PDF figures reported in the manuscript
are retained in `paper_results/`. After reproducing the formal experiment
directories, rebuild every manuscript artifact with

```bash
python paper_results/build_paper_results.py
```

The build performs completeness checks before writing the final artifacts.
Raw simulation and GTEx files generated during a full run are excluded from
version control because they can be regenerated by the commands above.
